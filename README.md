Title – ChickPeas classification datasets.

Description – The proposed research has been used to classify White and Black Chickpeas using image processing and deep learning techniques. All the relevant prepared data and code is available on Github with following link.  https://github.com/sanjayksingh012/ChickPeas  

Dataset Information:- For this purpose, 25 black multi-chickpeas and 28 white multi-chickpeas images have been captured using proposed image acquisition method and stored in folder BlackCp and WhiteCp respectively in Github repository. Total of 1432 single black chickpea and 948 single white chickpea images has been generated from multi-chickpeas images and stored in two folder Black_Cp and White_Cp respectively.

Code Information: The code for proposed work has mainly divided in following steps:
a.	Load Data Set: Load the images available for single black and white chickpeas from Black_Cp and White_Cp folder. Total of 2380 single chickpeas images has been loaded.
b.	Data Augmentation: Total of 8616 single chickpea images includes 4376 black chickpea and 4240 white chickpea images has been generated after proposed data-augmentation techniques. Each true-color chickpea images resized to 75 x 75 x 3 size for uniformity and simplicity.
c.	Feature Extraction: Total of 7680 features (1024 using DenseNet121, 2048 using ResNet50, 2048 using InceptionV3, 2048 using Xception and 512 using VGG19) has been extracted for each image of dataset. The final feature vector size using different pre-trained networks will be shown in table 4.A combine all feature set has been generated by combining all feature having size 8616 x 7680.
d.	Classification: The total of 8616 samples divided into 6031 training samples and 2585 testing samples. Three classifiers support vector machine, decision tree and random forest classifier has been trained with 5 fold cross validation on feature extracted using DenseNet121, ResNet50, InceptionV3, Xception, VGG19 and combine all features.

Usage Instructions: – 
•	File “load_data.ipynb” used to load data set.
•	File “load_data_aug.ipynb” used to augment data.
•	File “feature_extract.ipynb” used to extract the feature using proposed transfer learning menthods on augmented data.
•	File “Chickpeas_Classification.ipynb” used for classification of black and white chickpeas using proposed approach.  
Requirements – Basic Python libraries such as opencv, pandas, matplotlib will be required for data preprocessing. Tensorflow library will be required for feature extraction and model training.
All the experiments have been carried on 11th Generation Intel Core i7-11600H, 2.9 GHz Base Speed, up to 4.6 GHz Max Turbo Speed, 6 Cores, 12 Threads,18MB Cache16GB (8GB SO-DIMM *2) DDR4 3200MHz with Dedicated NVIDIA GeForce RTX 3050 GDDR6 4GB VRAM and running Windows 10 Home (64bit).
